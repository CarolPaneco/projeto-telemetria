Blocos válidos (área liberada)

Base geográfica usada para validar e relacionar as ocorrências.
Nenhum arquivo carregado
Envie o arquivo com os blocos (exportado da tabela SHAPE_GERAL_TEREOS) para validar se cada ocorrência está dentro de um bloco. Aceita CSV ou JSON, com a coluna GEOMETRY em formato WKT (ex: POLYGON((...))) ou GeoJSON — o sistema detecta sozinho. Uma vez enviado, os blocos ficam salvos neste navegador e não precisam ser reenviados a cada análise.
Nenhum bloco carregado
Colunas reconhecidas (nomes flexíveis, maiúsc./minúsc. e acentos não importam): GLEBA, BLOCO, TALHAO, UNIDADE, GEOMETRY. Em JSON, também aceita uma lista de Features no padrão GeoJSON (geometry + properties).

Base de estimativas de cana

Produção estimada utilizada no cálculo das toneladas.
Nenhum arquivo carregado
Envie a base de estimativas por talhão para deixar os dados salvos neste navegador. Essa base será usada para relacionar SAFRA + GLEBA + BLOCO + TALHÃO com a telemetria GPS. Quando disponível, o cálculo usa a produção estimada do bloco e distribui as toneladas proporcionalmente aos metros trabalhados na ocorrência.
Nenhuma base carregada
Aceita CSV, TXT ou JSON. A base pode conter, entre outras, as colunas SK_ESTIMATIVAS, DS_ANO_SAFRA, DS_GLEBA, DS_BLOCO, DS_TALHAO, DH_DATA_ESTIMATIVA, VL_AREA, VL_ESPACAMENTO_TALHAO, VL_PRODUTIVIDADE e VL_PRODUCAO_ESTIMADA. Os dados ficam salvos neste navegador e não precisam ser reenviados a cada análise.
